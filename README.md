# Arisou-Nitsugu-Kokuyu

**ありそうな告諭風のビラ**を、好きな文面でつくって眺める Web のおもちゃです。旧い印刷物を思わせる縦書きと、文字のずれやかすれを楽しめます。

> これは架空のビラをつくる道具です。実在の団体による告諭や特定の史料、当時の印刷技法の正確な再現を保証するものではありません。

## できること

- 表題・本文・日付・差出人を入力し、縦書きでプレビュー
- 白紙・生成り・古紙の紙色、文字のゆらぎ、印刷のかすれを調整
- 「風合いを変える」で同じ文面の紙の粒や文字のずれ・かすれを作り直す
- できあがったビラを 1200 × 1650 ピクセルの PNG 画像として保存

画像の生成はブラウザ内で完結し、入力内容や画像はサーバーに送信されません。文章そのものを自動生成する機能はありません。

## 使い方

Node.js と npm を用意し、リポジトリで以下を実行します。

```sh
npm install
npm run dev
```

表示された URL を Canvas に対応したブラウザで開きます。入力はプレビューに反映されます。本文は改行ごとに次の縦の列から始まり、長い文は自動で折り返されます。画像を保存するには、必要に応じて編集欄の「ファイル名」を入力し、「画像を保存」を押します。ファイル名が空欄（空白のみの場合を含む）なら、保存時の端末のローカル日時を使って `告諭_YYYYMMDD_HHMM.png` になります。入力した名前に `.png` がなければ自動で付けます。ブラウザや OS により、使用できない文字などは変更される場合があります。

かすれやゆらぎを強くすると、文字が欠けたり重なったりして読みにくくなる場合があります。紙のざらつきも画像に描き込まれます。

表題・日付・差出人は各40文字、本文は600文字までです（ブラウザの文字数の数え方によります）。長い文や改行が多い文は紙面に収めるため小さくなり、極端な場合は読みにくくなります。記号や英数字の縦書き表現は簡易的なものです。フォントの読み込みに失敗した場合は、端末の明朝体などに代替され、見た目が変わることがあります。

## ビルドとテスト

```sh
npm run build
npm run preview
node --test
```

書体には [Noto Serif JP](https://github.com/googlefonts/noto-cjk)（SIL Open Font License 1.1）を使用しています。
